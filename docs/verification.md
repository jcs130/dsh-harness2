# 验证范围与已知边界

验证环境：Node.js 24.19.0、Windows + Ubuntu-22.04 / Python 3.12.14、DSH 0.2.1-rc.2。
Google Harness² 固定到 `1cfe254e8d25b15f37048c3730134686abe60335`。本地验证未调用付费模型，未启动 Minecraft，未加载或重启现役 Agent。

验证分开记录：

1. Node 测试：任务身份、原版/候选/留出场景、取消、防重放、未知清理、缺失用量、宿主记忆去重、元数据隐私与包依赖约束。
2. 真实 DSH：插件与 ToolRuntime 注册、所有者鉴权 / delegate 拒绝、RPC envelope、卸载清理、翻译与图标读取。
3. DSH DeepSeek Adapter：本机 SSE 夹具，检查独立会话 header、保持思考设置与输出预算、最终 usage，不调用云端。
4. 真实 Google 执行器：并行 k=1、顺序 k=2，实际声明式任务试跑、留出复测、已完成任务零作用恢复。模型是确定性夹具，token 量保持未知。
5. 原生组件：对实际编译的客户端模块做 React 渲染、未知/空状态与文本转义检查。这不等于 Desktop 原生窗口画面验收。
6. 打包 / 默认 pnpm / DSH 独立 profile 安装：以随交付的 `assessment.json` 和安装日志为准，不能把源码测试或 npm pack 成功当成安装完成。

npm 补发验收：registry 匿名下载与 GitHub 安装包字节一致，固定版本 `@jcs130/dsh-harness2@0.1.0-rc.1` 通过 DSH 0.2.1-rc.2 / pnpm11.28.5 独立 profile 安装与实际模块加载。所有者统计接口返回 200，delegate 被拒绝，卸载后返回 404，全程零模型与游戏调用。pnpm 默认行为为显式安装的刚发布版本自动记录一条精确的 `minimumReleaseAgeExclude`；测试记录了这一 profile 变更，没有手动关闭发布时间门槛或改动全局设置。

首次实际 Harness² 试跑发现默认声明没有明确引用任务技能，导致上游补触发声明后与不可变部分冲突。修复为初始化时声明技能，并在任何回调前验证原始树。失败实验保留，修复后以新 jobId 运行，没有重置原证据。

目前支持的是受约束的实验框架和演示任务，不是随意修改整个 DSH 的通用自动升级器。真实模型效果、成本收益、长期跨任务改善、任意办公/代码执行器及线上采用效果尚未验证。市场状态与 npm 登录状态单独记录。
